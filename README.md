# Wayss AI

Wayss is an all-in-one AI assistant prototype with a connected Node/Express backend and responsive web frontend.

## Features
- AI chat
- Text-to-image generation
- Image analysis and editing
- Code mode
- File upload/context
- Web search via Tavily
- Voice input
- Local chat history
- Email/password authentication

## Deploy
Railway can run the root project. Set the environment variables from .env.example.

Required for AI:
- OPENAI_API_KEY

Optional:
- TAVILY_API_KEY
